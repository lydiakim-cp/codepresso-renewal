FAQ

시작 전에 많이 묻는 질문

사전 지식이 없어도 되나요?

괜찮습니다. 진단 인터뷰가 현재 수준을 먼저 확인하고 입문 레벨부터 경로를 만듭니다. 이미 아는 영역이 있으면 그 구간은 건너뜁니다.

하루에 얼마나 써야 하나요?

하루 30분에서 1시간을 기준으로 2~3주 계획을 만듭니다. 스킬 단위로 끊어져 있어 시간이 날 때 한 스킬씩 진행할 수 있습니다.

설치할 프로그램이 있나요?

없습니다. 코드 작성과 실행, 채점이 모두 브라우저 안에서 이뤄집니다. 개발 환경을 맞추다 첫 주를 보내는 일이 없습니다.

어떤 언어와 기술을 다루나요?

Python · Java · JavaScript · C++ · SQL · Git · Linux 같은 기본기부터 프롬프트 엔지니어링 · LangChain · LangGraph · PyTorch · TensorFlow까지 51개 트랙을 제공합니다.

진단 결과가 정확한가요?

대화형 진단이라 첫 결과에는 오차가 있습니다. 대신 학습을 시작한 뒤의 정답률과 제출 코드가 계속 반영되어 경로가 조정됩니다. 진단은 한 번의 판정이 아니라 계속 고쳐지는 추정입니다.
