# 반례 — 넣었다가 걷어낸 것

이 목록은 **Claude가 넣었고 사용자가 지운 것**을 모은 것이다. 규칙보다 강한 자료다 —
"하면 안 된다"가 아니라 "실제로 해봤고 되돌렸다"이기 때문이다. 새 섹션·페이지를
만들기 전에 이 표를 먼저 훑는다. 여기 있는 것을 또 넣으면 같은 수정이 반복된다.

## 되돌린 목록

| 넣었던 것 | 왜 아니었나 | 대신 |
|---|---|---|
| 텍스트 블러, 섹션 안 구분선, 유리 질감 남발 (`ecfdb76`) | 장식이 정보보다 먼저 보인다. 메인 랜딩에서 통째로 걷어냈다 | 면(surface ramp)과 여백으로 구분한다 |
| 클릭되지 않는 카드에 hover 부상·그림자 (`815773d`) | 누를 수 있다는 거짓 신호. 판 전체가 링크가 아니면 판에 hover를 주지 않는다 | 안쪽 링크·버튼에만 준다 |
| 본문 중간에 `statement` 강조 띠 추가 (`f61862c`) | 전체 폭 강조가 두 곳이면 둘 다 안 읽힌다 | **페이지당 1곳**. 이미 있으면 새로 넣지 않는다 |
| 새 강조색(그린) 도입 (`7d9ff64`) | 브랜드 파랑 하나로 충분하다. 색이 늘면 위계가 흐려진다 | `--color-brand` 계열 + 면 톤으로 구분한다 |
| 아이콘 크기를 그때그때 px로 (`247d400`→`8d1cf3c`→`df99a5c`, 세 번 되돌림) | 매번 다른 값이 들어갔다 | `.icon-sm/md/lg` 3클래스로만. 박스와 글리프는 짝(sm↔32, md↔48) |
| 제목·수치를 큰 값으로 시작 (h2 44px, hero 수치 32px) (`7bec347`, `2b6380f`) | 화면이 소리친다. 위계는 크기 차이가 아니라 색·굵기로도 난다 | h2 40px, hero 보조 수치 20px. 토큰 밖 값을 쓰지 않는다 |
| 본문 폭을 넓게 (1280px) (`6b2b30c`) | 한 줄이 길어 읽기 흐름이 끊긴다 | `--container-medium` 1248px(실 콘텐츠 1208px) |
| 어두운 판을 여러 섹션에 (`63e32ba`) | 강조가 흔해지면 강조가 아니다 | 페이지에 어두운 판은 1곳. 나머지는 흰 면·옅은 틴트 교차 |
| 카드 안에 accent 세로/상단 띠 | "이 카드가 특별하다"를 띠로 말하면 카드가 다 시끄러워진다 | 면·경계선 색·아이콘 색으로 말한다 (구현을 우회한 4px 띠도 같은 위반) |
| 배경 리듬을 `surface-sunken` + `brand-tint-1`로 (실제 지적) | 두 색이 사실상 같고 흰색과 6% 차이라 화면이 허여멀건해진다 | `css-patterns.md` 4번의 실측 대비 표에서 고른다 |
| 컴포넌트를 페이지 전용으로 새로 만들기 (`4e0bfce`, `ed29449`, `7b41b5e`에서 공용 승격) | 같은 역할이 페이지마다 다른 CSS로 갈라졌다 | 역인덱스에서 고르고, 없으면 묻는다 |
| CSS에 시행착오·배경 설명을 길게 주석 (`86c9f3b`에서 3181줄 삭제) | 정작 판단에 필요한 한 줄을 찾지 못한다 | 파일 첫머리 2줄 + 판단이 갈렸던 지점만 한 줄. 나머지는 커밋 메시지로 |
| 스타일 없는 설명용 클래스를 마크업에 남기기 (`63ba829`에서 16개 제거) | 있는 것처럼 보이는 훅이 다음 사람을 속인다 | CSS·JS가 실제로 쓰는 클래스만 마크업에 둔다 (`page-audit`가 검사) |

## 이 목록을 늘리는 방법

사용자가 직접 고친 뒤 **"내가 고친 것 반영해줘"** 라고 하면:

```bash
node .claude/skills/html-css-architecture/scripts/harvest-feedback.js
```

마지막으로 회수한 지점 이후의 CSS·HTML 변경만 뽑아 준다. 그중
**"Claude가 넣었고 사용자가 지운 것"** 만 위 표에 한 줄로 올리고
(넣었던 것 · 왜 아니었나 · 대신 무엇), 그 다음 마커를 갱신한다:

```bash
node .claude/skills/html-css-architecture/scripts/harvest-feedback.js --update-marker
```

**규칙으로 올릴 수 있는 것은 표에 두지 말고 게이트로 내린다** —
값·클래스처럼 기계가 검사할 수 있으면 `token-lint`·`page-audit`에 규칙을 더한다.
이 표는 기계가 판정할 수 없는 것(취향·절제·강조의 배분)만 남기는 자리다.
